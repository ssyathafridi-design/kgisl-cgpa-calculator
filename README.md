# KGiSL CGPA Calculator

A simple web-based CGPA calculator for KGiSL Institute of Technology students.

## Features

- Upload result screenshot (OCR auto-fill)
- Manual entry option
- Calculate SGPA and overall CGPA
- Save semester history
- Download result as PDF

## How to Use

1. Open the website
2. Upload your result screenshot OR enter subjects manually
3. Click "Calculate My CGPA"
4. Save semester and track overall CGPA

## Tech Stack

- HTML, CSS, JavaScript
- Tesseract.js (OCR)
- jsPDF (PDF generation)

## For Students

Made for KGiSL students. Verify results with official college portal.
